# Andreas Portfolio

This portfolio presents some of Andreas' web development work. The current selected projects are from the front-end studies.

- Live website: [https://andreasthune.no/](https://andreasthune.no/)

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

1. Clone the repo:

```bash
git clone https://github.com/Andy19955/Portfolio-2.git
```

2. Navigate to the project directory:

```bash
cd Portfolio-2
```

3. Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `npm run dev` - start the development server
- `npm run build` - build the app for production
- `npm run start` - start the production server
- `npm run lint` - run ESLint
